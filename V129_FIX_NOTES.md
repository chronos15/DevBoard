# TaskBoard V129 — editar imagem antes do envio

## Alteração
- Adicionado botão de lápis no card de preview de imagens pendentes no Acompanhamento.
- O botão abre o mesmo editor de imagem já existente no TaskBoard.
- Ao concluir a edição, o arquivo original é substituído pela nova imagem editada no composer.
- Somente a versão editada permanece na fila e será enviada.
- A validação de limite por arquivo/lote é executada novamente após a edição.
- Vídeos e demais anexos mantêm o comportamento anterior.

## Banco de dados
Nenhuma migration nova.
